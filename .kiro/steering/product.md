# Product: Math Multiplication Trainer

A children's multiplication table practice app (tabuadas). Kids practice tables 2–10 by answering timed questions, unlock new tables through mastery, and track their progress.

## Core Features

- **Table Selection**: Choose a specific multiplication table (2–10) to practice
- **Random Practice**: Mixed questions from tables 3–9
- **Progressive Unlock**: New tables unlock when mastery threshold is met on the current table
- **Feedback System**: Immediate correct/incorrect feedback after each answer with timed overlay
- **Session Timer**: Tracks time spent per practice session
- **Response Time Tracking**: Records how quickly each question is answered
- **Statistics Screen**: Shows progress and mastery levels per table
- **Unlock Celebration**: Visual celebration when a new table is unlocked
- **Persistence**: Progress saved to localStorage

## Target Audience

Children learning multiplication tables. The UI language is Brazilian Portuguese.
